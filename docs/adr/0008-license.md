# ADR-0008: License

Date: 2026-09-21

## Context

User decision (asked explicitly per the brief).

## Decision

Apache-2.0.

## Why

Explicit patent grant and clearer contribution terms than MIT, which matters more once the
project accepts outside contributions (this is meant to be a real open-source repo, not a
gist). `LICENSE` file added at repo root in Phase 6 (or now, trivially, if useful earlier).
